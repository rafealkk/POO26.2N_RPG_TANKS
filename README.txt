# RPG Tanks — Jogo de Combate de Tanques

Projeto acadêmico desenvolvido em **TypeScript**, durante a disciplina de Programação Orientada a Objetos (POO) do curso de Análise e Desenvolvimento de Sistemas.

O projeto consiste em um jogo de combate entre tanques de guerra, executado diretamente no terminal, com diferentes classes de veículos, equipamentos e mecânicas de batalha.

## Tecnologias utilizadas

- TypeScript
- Node.js
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Funcionalidades

- Sistema de combate entre tanques.
- Diferentes classes de tanques, incluindo leves e pesados.
- Gerenciamento de vida, munição e combustível.
- Sistema de ataque e cálculo de chance de acerto.
- Mecânicas de reparo e utilização de equipamentos.
- Interação entre objetos por meio de classes e métodos.

## Conceitos de programação aplicados

O projeto foi desenvolvido com o objetivo de colocar em prática conceitos de Programação Orientada a Objetos, como:

- **Encapsulamento:** proteção e gerenciamento dos atributos dos tanques.
- **Herança:** criação de subclasses de tanques com características específicas.
- **Abstração:** representação dos veículos e equipamentos por meio de classes.
- **Polimorfismo:** utilização de comportamentos específicos das diferentes classes de tanques.

## Objetivo do projeto

Desenvolver uma aplicação interativa utilizando TypeScript, aplicando os conhecimentos adquiridos durante a graduação e explorando a organização de código, a reutilização de componentes e a lógica de programação.

## Melhorias planejadas

O projeto está em desenvolvimento e poderá receber novas funcionalidades, incluindo:

- Integração com a API do Google Gemini para geração dinâmica de diálogos entre os tripulantes dos tanques.
- Utilização da biblioteca Faker para geração de dados aleatórios.
- Expansão das mecânicas de combate.
- Novos tipos de tanques e equipamentos.

A proposta da integração com inteligência artificial é permitir que os tripulantes reajam aos acontecimentos da batalha, gerando falas contextualizadas de acordo com as ações realizadas durante o jogo.
